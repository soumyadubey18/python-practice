# Strings
A string is text.

Important: indexing `text[0]`, slicing `text[1:4]`, reverse `text[::-1]`, `upper`, `lower`, `strip`, `split`, `join`, `find`, `replace`, `count`.

```python
text = "Python"
print(text[::-1])
```

**Logical:** palindrome, character count, password validator.

**AWS idea:** process log lines, server names and configuration values.
