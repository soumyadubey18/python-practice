# Dictionaries
A dictionary stores key/value pairs.

```python
server = {"name": "web01", "status": "running", "cpu": 70}
print(server["status"])
```

Useful: `keys()`, `values()`, `items()`, `get()`, `update()`.

**AWS:** API responses commonly contain nested dictionary/list structures.
