# Functions
A function is reusable code.

```python
def add(a, b):
    return a + b

print(add(10, 20))
```

`def` defines; name identifies; parameters receive input; `return` sends a result back.

Trainer topics: parameters, positional/keyword/default arguments, `*args`, `**kwargs`, lambda, recursion.
