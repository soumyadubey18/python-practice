# Python Definitions — Very Easy Language

Use this folder whenever a Python word is confusing.

- **Python**: a programming language used to give instructions to a computer.
- **Program**: a set of instructions.
- **Syntax**: rules for writing Python correctly.
- **Variable**: a name that refers to a value. Example: `name = "Soumya"`.
- **Data type**: the kind of data, such as `str`, `int`, `float`, `bool`, `list`, `set`, `dict`.
- **String**: text inside quotes.
- **Integer**: a whole number.
- **Boolean**: `True` or `False`.
- **Operator**: something used to calculate/compare/combine values.
- **Condition**: a True/False decision.
- **Loop**: repeats code.
- **Function**: reusable block of code.
- **Parameter**: variable in a function definition.
- **Argument**: actual value passed to a function.
- **Return**: sends a value back from a function.
- **Module**: a `.py` file containing reusable code.
- **Import**: brings a module/function into the current program.
- **List**: ordered, changeable collection.
- **Tuple**: ordered, generally immutable collection.
- **Set**: collection of unique values.
- **Dictionary**: key/value collection.
- **Mutable**: contents can be changed.
- **Immutable**: contents cannot be changed in place.
- **Exception**: runtime problem/error.
- **JSON**: common structured-data format.
- **API**: communication interface between programs/services.
- **Boto3**: AWS SDK for Python.

## Easy mental model

```text
Variable    = name for data
Condition   = decision
Loop        = repeat
Function    = reusable machine
Module      = toolbox/file
Dictionary  = key -> value
Set         = unique values
Exception   = runtime problem
API         = communication bridge
Boto3       = Python -> AWS bridge
```
