# Mock Interview Practice

Try these WITHOUT looking at solutions.

## Basic logic
1. Take a number and print whether it is even or odd.
2. Find the greatest of two numbers.
3. Check whether a number is positive, negative or zero.
4. Check whether a number is divisible by both 5 and 10.

## Loops
5. Print numbers 1-20.
6. Print even numbers from 1-50.
7. Find the sum of 1-100.
8. Print a multiplication table.

## Strings
9. Reverse a string without using a reverse method.
10. Check palindrome.
11. Count vowels.
12. Count uppercase, lowercase, digits and special characters.

## Lists
13. Find largest number without max().
14. Remove duplicates.
15. Count even numbers.
16. Find common elements between two lists.

## Dictionaries
17. Print all keys and values.
18. Find servers whose status is running.
19. Count occurrences of words using a dictionary.
20. Merge two dictionaries.

## Functions
21. Create an add function.
22. Create a function that checks server health.
23. Create a password validator.
24. Demonstrate *args and **kwargs.

## Modules
25. Create calculator.py and import it.
26. Import math using an alias.
27. Import factorial directly.
28. Use os, datetime and json.

## Trainer-style oral questions

- Difference between = and ==?
- Difference between == and is?
- What does input() return?
- What is mutable vs immutable?
- Why do we use functions?
- print vs return?
- What is *args?
- What is **kwargs?
- What is a module?
- Difference between import module and from module import function?
- What is __pycache__?
- Why are strings immutable?
