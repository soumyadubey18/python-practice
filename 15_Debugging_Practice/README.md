# Debugging Practice

Find the error before looking at the hint.

### Q1
```python
if 10 > 5
    print("Yes")
```
Hint: syntax.

### Q2
```python
def add(a, b)
    return a + b
```
Hint: function definition.

### Q3
```python
age = input("Age: ")
print(age + 5)
```
Hint: data type.

### Q4
```python
for i in range(1, 5)
    print(i)
```
Hint: `for` syntax.

### Q5
```python
server = {"status": "running"}
print(server["name"])
```
Hint: dictionary key.

### Debug checklist
1. Read error type.
2. Read line number.
3. Check spelling.
4. Check indentation.
5. Check brackets/quotes/colon.
6. Check data types.
7. Check variable names.
8. Check keys/indexes.
